F ring mosaics bundle: open items
=================================

Open
----

- cassini:limitations is not emitted. The PDS3 LIMITATIONS field is free text
  that does not parse cleanly, so the value would have to be cleaned up before
  it could be written. The published cassini_iss_saturn labels carry it.

- Number formatting differs from the published cassini_iss_saturn labels in a
  few cassini: fields, which print the PDS3 value as given rather than to a
  fixed number of decimals: exposure_duration "820." against "820.000000",
  inst_cmprs_rate_expected_bits "2.67303" against "2.673030". Both forms are
  valid ASCII_Real.

- rings:description repeats text that the Rings dictionary itself should
  carry. Revisit when the dictionary definitions are next revised, along with
  the corotating longitude wraparound clause, which the Node has said it will
  change.

Waiting on others
-----------------

- urn:nasa:pds:context:target:star.l02_pup is referenced by the four L2PUPOCC
  observations, collection_context.csv, and the bundle and collection labels.
  The context product exists at PDS as of 2026-09-03 but is absent from the
  list shipped with validate 4.2.0, so the stock tool reports 49 unresolved
  references.

- collection_xml_schema.csv carries the LIDVIDs the dictionary labels
  themselves declare, read from https://pds.nasa.gov/datastandards/dictionaries/ :

    pds-xml_schema_1.24.0.0::1.0
    disp-xml_schema_1.24.0.0_1.5.1.0::1.0
    geom-xml_schema_1.24.0.0_1.9.11.0::1.0
    rings-xml_schema_1.24.0.0_1.15.0::1.0
    cassini-xml_schema_1.24.0.0_1.8.0.0::1.0

  Read them out of the dictionary label; do not derive them. The registry has
  not ingested the Information Model 1.24 products yet, so validate reports
  these as unresolved until it does.

- The 20,584 data_calibrated source references and the iss-data-user-guide::2.0
  inventory rows resolve when the coordinated Cassini ISS delivery is
  published.

- The bundle DOI 10.17189/3tfh-th07 and the user guide DOI 10.17189/ajhh-aj88
  do not resolve until the Node mints them.
